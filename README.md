# Gustavo Souza — Portfólio Profissional

Portfólio de página única criado para apresentar a formação, experiência e competências profissionais de Gustavo Souza.

## Executar localmente

1. Instale o Node.js 22.13 ou superior.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Abra o endereço indicado no terminal.

## Gerar a versão de publicação

Execute `npm run build`. A saída será criada na pasta `dist`.

## Conteúdo e arquivos públicos

A fotografia e o currículo estão em `public/assets`. Para atualizá-los, preserve os nomes dos arquivos ou ajuste os links em `app/page.tsx`.
